# Historical SystemSense documents

This directory preserves the previous documentation tree at consolidation. Original `docs/` paths retain their relative layout here (`architecture/` and `plans/`). `README-before-consolidation.md` and `AGENTS-north-star-draft.md` preserve the two former entry points, including the uncommitted AGENTS draft present at consolidation.

These records include superseded plans, status reports, proposed designs, audits, qualification notes, and synthetic episodes. Claims are time- and revision-bound and may contradict one another. They are **not** instructions or evidence of the current build. Use the five documents in the parent directory for present product guidance; open this archive only when tracing history. Historical links to former root paths may not resolve after relocation.
